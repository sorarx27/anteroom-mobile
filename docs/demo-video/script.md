# Anteroom demo - voice-over script

Ninety-one seconds. These lines are the `<voiceover>` blocks in
`storyboard.xml`, the burned-in captions, and the narration on
`anteroom-demo.mp4` - all the same strings, so none of them can drift.

## About the voice on the master

It is macOS `say` (Daniel, en_GB), generated by `pipeline/voice.py` and
fitted to each shot by adjusting speaking rate rather than clipping audio.
It is clear and correctly timed, and it is obviously synthetic.

**Re-record it in your own voice if you can.** A clinician narrating their
own clinical-safety argument is worth more than any amount of production
polish, and the pipeline makes the swap cheap: read against the table below,
then

```
ffmpeg -i anteroom-demo-silent.mp4 -i your-vo.wav \
       -c:v copy -c:a aac -b:a 192k anteroom-demo.mp4
```

## Notes for the read

- The payoff is `flag-1`. Slow down; it is the one claim in this video that
  no other submission can make.
- Do not say the AI reads it perfectly. The point is the opposite - it read
  seven of eight and said so.
- `generate-2` carries an on-screen label saying model time was trimmed.
  Do not imply it was instant.
